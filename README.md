# My portfolio

A small corner of the internet for my AI, robotics, and computer vision work. Built with plain HTML, CSS, and JavaScript, with a little Star Wars influence.

## Run locally

Run `python -m http.server 8000` in this directory, then open `http://localhost:8000`.

## GitHub Pages

The site runs directly from the root of the `main` branch. In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save.

No build step or API keys are needed. The site uses Google Fonts, with local font fallbacks. Project links lead to my repositories and demos.
